# Amazon India Dashboard
## Project Objective
The main objective of this project is to design a simple and easy-to-understand management dashboard for Manoj to
submit to his manager, Ravi, who comes from a non-technical background.
## Dataset used
- <a href="https://github.com/Swethadalavaee/Amazon-India-Dashboard/blob/main/Amazon%20Sales%20Data%20India.xlsx">Dataset used</a>
## Questions
How is the business performing overall? 
Which products and categories perform best? 
How many orders are completed or lost? 
Which payment methods generate more business? 
Which fulfilment method performs best? 
Which states generate more business? 
## Project Process 
-Data Understanding: Reviewed columns such as Order Date, Category, Product, Quantity, Sales, Profit and Order Status.
-Data Cleaning: Checked the dataset and prepared the data for analysis.
-Data Analysis: Analyzed sales, profit, products, orders, payment methods and states.
-Calculated important business metrics such as total sales, profit margin and average order value.
-Dashboard Creation: Created charts, graphs and pivot tables for each question and merged all to make a dashboard
